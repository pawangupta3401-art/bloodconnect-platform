# 🩸 BloodConnect — Real-Time Blood Inventory & Donor Platform

**VORTEX Hackathon 2026 — PS-01**

🔗 **Live Demo:** [bloodconnect-platform-git-main-pawangupta3401-arts-projects.vercel.app](https://bloodconnect-platform-git-main-pawangupta3401-arts-projects.vercel.app/)

## Problem
Blood banks face shortages or wastage because inventory and donor availability aren't visible in real time. 12,000+ preventable deaths occur daily in India due to this gap.

## Solution
A centralized platform connecting blood banks, hospitals, and donors — with real-time inventory, emergency request routing, donor verification, and fraud prevention.

## Key Features
- Real-time inventory dashboard with compatibility-aware matching
- Emergency SOS with voice-guided requests (Hindi + English)
- Proactive redistribution engine (reduces wastage before expiry)
- Fast Drone Transport with live tracking
- Community/NGO broadcast fallback (WhatsApp, Instagram, Telegram)
- Aadhaar-hash donor verification & fraud detection
- Tamper-evident audit ledger

## Tech Stack
React.js · Node.js · Express · PostgreSQL · MongoDB · Socket.io · Tailwind CSS
